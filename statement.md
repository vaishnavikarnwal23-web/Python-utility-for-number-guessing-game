1. Problem Statement



The objective of this project is to design a simple Number Guessing System

in Python. The computer will pick a random number and the user will have

to guess what it is. The program will then give the user hints and tell

them if the number they guessed was too high or too low.



2. Scope of the Project



The scope of this project is to design a simple and interactive number

guessing game using the basic concepts of the Python language. It includes

selecting the levels of difficulty, picking the random number, validating



any entry made by the user, counting the number of attempts made by the

user and calculating the score based on the number of attempts made.

The project can be enhanced further by including a leaderboard, a timer

or a graphical user interface.



3. Target Users

The main target users are:

- Beginner python developers

- Students studying computer science

- Anyone interested in playing a number guessing game

4. High-Level Features

The features of the Number Guessing System are:

1. Selecting the difficulty level

The user will be able to choose between the Easy, Medium and Hard levels

of the game. Each level will be associated with a different range of

numbers.

2. Picking a random number

The computer will pick a random number within the range of numbers

selected by the user.

3. Making a guess

The player will be required to make a guess at the randomly picked number

by entering a number as input.

4. Validating the guess

The program will validate the input made by the user and check if it is

within the range of numbers.

5. Giving hints

The program will display a message "Too High" when the user makes a guess

higher than the secret number. It will also display a message "Too Low"

when the user makes a guess lower than the secret number.

6. Keeping track of the number of attempts

The program will count the number of attempts that the user takes to

guess the correct number.

7. Calculating the score

A score will be calculated based on the number of attempts made by the user

and the user will be notified.

8. Storing the best score

The program will keep track of the best score recorded during that session.

9. Playing again

The user will be given the option to play the game again.

10. Quitting the game

The program will display the best score and a thank you message when

the user decides to quit the game.

5. Expected Outcome

The expected outcome of this project is to build a working number guessing

game in Python that will allow a user to select their desired level, guess

the number selected by the computer, receive hints and score based on the

number of attempts it took them to guess the correct number.
